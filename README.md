# pixel-auto-backup

Wi-Fi 또는 USB로 PC 영상을 픽셀 1에 보내 구글 포토에 원본 화질로 자동 백업하는 윈도우 도구.

초기 검증 대상은 128GB 픽셀 1과 2560×1440 홈캠 영상 약 1TB다.

## 구성

- **윈도우 프로그램**은 네이티브 폴더 선택 창에서 지정한 원본 폴더를 읽기 전용으로 열고 파일 목록과 진행 상태를 관리한다. 구글 포토가 지원하지 않는 형식과 파일당 10GB를 초과하는 영상은 목록에 표시한다.
- **픽셀 보조 앱 오토픽셀**은 PC 주소와 6자 일회용 코드로 윈도우 프로그램과 페어링한다. 선택한 연결로 영상을 받고 진행 상태를 보낸다. PC에서 전송 시작을 누르면 픽셀의 가용 공간을 기준으로 묶음 크기를 정하고, 끊긴 전송을 이어받는다. 파일 해시가 원본과 일치한 뒤 픽셀의 DCIM/Camera에 공개한다.
- **구글 포토 앱**은 픽셀의 인터넷 연결을 통해 카메라 폴더의 영상을 지정한 계정으로 백업한다. 보조 앱은 잠금이 해제된 화면에서 접근성 서비스로 각 영상의 세부정보 확인을 시도한다.

## 프로그램 설정

| 설정 | 동작 |
| --- | --- |
| 원본 폴더 | 윈도우에서 읽기 전용으로 열 폴더를 지정한다. |
| PC와 픽셀 연결 | **Wi-Fi가 기본값**이다. 같은 네트워크에서 페어링하거나 USB 데이터 케이블 모드를 선택한다. USB 모드는 USB 디버깅 승인과 ADB 연결을 사용한다. |
| 묶음 크기 | 기본값은 **50GB**로, 윈도우 프로그램에서 변경할 수 있다. 실제 묶음은 설정값과 픽셀의 가용 공간을 함께 반영한다. |
| 픽셀에 남길 공간 | 작업 중 여유 공간을 얼마나 남길지 정한다. 새 묶음은 이 값을 반영해 크기를 줄이거나 공간이 확보될 때까지 기다린다. |
| 진행 상태 갱신 | **15초**마다 상태를 주고받고, 상태가 바뀌면 즉시 보낸다. |
| 픽셀 복사본 정리 | 확인이 끝난 묶음을 자동으로 정리할지, 윈도우 화면에서 승인한 뒤 정리할지 선택한다. 두 모드 모두 묶음 전체가 확인된 뒤에 정리한다. |

Wi-Fi와 USB는 PC와 픽셀 사이의 복사 및 상태 전송 경로다. 연결 방식을 바꾸면 같은 작업 기록에 이어서 진행한다.

## 백업 확인과 정리

1. 보조 앱은 각 영상의 식별값과 기기 미디어 ID를 기록한다. 파일명이 같은 영상은 별도 항목으로 추적한다.
2. 구글 포토의 영상 세부정보에서 대상 파일의 식별 정보, 백업 여부, 원본 화질을 확인한다. 예정된 계정도 확인한다.
3. 묶음의 모든 영상이 확인되면 정리 설정에 따라 보조 앱이 만든 픽셀 내부 복사본만 미디어 ID로 지정해 정리한다. 공간이 확보되면 다음 묶음을 받는다.
4. 영상별 상태나 계정을 확인할 수 없으면 묶음을 보관하고 중단 이유를 표시한다. PC와 픽셀에는 재연결과 재부팅 후 이어서 처리할 수 있도록 파일별 상태를 기록한다.

## PC와 픽셀 진행 화면

| 항목 | 표시 |
| --- | --- |
| PC에서 픽셀로 전송 | 현재 묶음의 전송 바이트와 복사 완료 파일 수 |
| 구글 포토 백업 확인 | 현재 묶음에서 원본 백업이 확인된 파일 수와 마지막 확인 시각 |
| 전체 진행 | 확인된 백업 용량과 전체 용량, 현재 묶음 |
| 픽셀 상태 | 마지막 상태 수신 시각, 충전·잠금 여부, 중단 이유 |

픽셀 앱은 시작할 때 접근성 서비스를 확인한다. PC에서 전송 시작을 누르면 구글 포토를 열 수 있는 알림을 표시한다. 연결과 백업 작업 중에는 알림을 표시하는 포그라운드 서비스로 실행한다. 상태가 바뀌면 즉시 전송하고, 변화가 없으면 설정한 간격으로 상태를 보낸다. 갱신 주기 네 번 동안 수신하지 못하면 마지막 값과 수신 시각을 표시한다. 재연결 시 픽셀이 현재 상태를 다시 보내고, PC는 파일별 기록을 기준으로 집계한다.

잠겨 있는 동안에는 마지막으로 확인한 구글 포토 백업 수와 시각을 표시한다. 장시간 백업은 충전 중에 실행하는 구성을 기준으로 한다.

## 실기기 검증 순서

- [ ] **영상 5~10개**로 픽셀 1의 구글 포토 화면에서 파일 식별 정보, 백업 상태, 원본 화질을 읽을 수 있는지 확인한다. 미백업 영상, 이름이 같은 다른 영상, 이미 백업된 영상을 함께 시험한다. 픽셀 8 프로에서 재생하고 웹에서 내려받은 표본의 해상도와 해시를 원본과 비교한다. 계정 저장용량 사용 여부도 확인한다.
- [ ] **1~5GB 묶음**에서 Wi-Fi와 USB를 각각 시험하고, 연결이 끊겼거나 연결 방식을 바꿨을 때 같은 작업을 이어갈 수 있는지 확인한다. 화면이 꺼진 상태의 진행 갱신, 재접속 후 집계, 확인되지 않은 파일의 보관, 자동 및 승인 후 정리를 확인한다.
- [ ] **기본값인 50GB로 묶음 하나**를 끝까지 돌려 전체 흐름과 처리 시간을 확인한 후 약 1TB로 확대한다.

첫 검증에서 필요한 구글 포토 정보가 접근성 기능에 노출되는지 확인한다. 안정적으로 읽을 수 없으면 자동 전송까지 진행하고 백업 확인과 정리는 수동으로 처리한다.
