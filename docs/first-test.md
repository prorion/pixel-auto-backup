# 오토픽셀 0.3 첫 실기기 시험

윈도우 실행 파일은 Windows 10/11 x64, 픽셀 APK는 Android 10 이상용이다. PC와 픽셀 모두 0.3으로 업데이트해 시험한다. APK는 기존 시험판 위에 설치할 수 있다.

## 연결하고 전송하기

1. 홈캠 영상 2~3개를 시험 폴더에 복사한다. PC의 **백업 설정**에서 **폴더 선택…**으로 시험 폴더를 고르고, 구글 포토 계정을 입력한 뒤 저장한다.
2. 픽셀에서 **오토픽셀**을 열고 **접근성 설정 열기**로 **오토픽셀 · 포토 확인**을 켠다. 앱으로 돌아오면 진행과 연결 화면이 열린다.
3. PC의 **진행 및 연결**에서 **새 연결 코드 만들기**를 누른다. Wi-Fi에서는 PC 주소와 6자 코드를 폰에 입력한다. 네 번째 문자를 입력하면 하이픈이 들어간다. 이전에 연결한 같은 기기와 PC라면 **기존 연결 재개**를 사용할 수 있다.
4. 양쪽 연결 상태를 확인하고, PC에서 **전송 시작**을 누른다. 폰에서 구글 포토를 열라는 메시지나 알림을 누른다. 앱에 돌아와 **구글 포토 열기 · 백업 확인**을 직접 누를 수도 있다.
5. 새 영상은 픽셀의 **DCIM / Camera**에 저장된다. 구글 포토의 기본 **백업**이 켜져 있는지 확인한다. 폰의 **저장 폴더 열기**와 **받은 파일 목록**에서 복사본을 찾을 수 있다.
6. 양쪽에서 **원본 백업 확인** 건수를 확인한다. 백업 계정 확인을 기다린다면 구글 포토의 **프로필 → 포토 설정 → 백업** 화면을 연다. 영상 세부정보가 자동으로 열리지 않으면 대상 영상을 열고 위로 쓸어올린다.
7. 묶음 전체가 확인되면 PC에서 **확인된 묶음 정리**를 눌러 복사본을 정리할 수 있다. 실제 첫 시험에서는 같은 계정의 다른 기기에서도 영상을 재생해 본다. 자동 정리는 기본적으로 꺼져 있다.

Wi-Fi 방화벽 안내가 나오면 신뢰하는 사설 네트워크에서 연결을 허용한다. 폰 알림을 받으려면 오토픽셀 알림을 허용한다. 화면을 잠그면 구글 포토의 화면 확인은 잠금이 풀릴 때까지 대기한다.

## USB 연결

[Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools)를 설치하고 ADB를 Windows PATH에 둔다. 데이터 케이블을 연결한 뒤 픽셀에서 USB 디버깅을 승인한다. PC에서 연결 방식을 USB로 선택하고 코드를 만든 다음, 픽셀에서 **USB로 연결**을 켜고 코드를 입력한다.

## 픽셀 8 프로로 먼저 시험하기

같은 PC에서 픽셀 8 프로를 먼저 시험하면 PowerShell에서 별도 프로필로 실행한다. 실행 중인 오토픽셀 창을 닫고 압축을 푼 폴더에서 실행한다.

```powershell
.\pixel-auto-backup-windows-x64.exe -data "$env:LOCALAPPDATA\PixelAutoBackup-Pixel8-Test"
```

픽셀 1에는 기본 프로필을 사용할 수 있다. 픽셀 8 프로의 구글 포토 업로드는 계정 저장용량에 반영된다.

## 확인이 멈췄을 때

폰 첫 화면의 완료 수, 대기 이유, 마지막 확인 시각을 본다. 상세한 화면 판정은 **진단 보기**에서 확인한다. 문제를 공유할 때는 기기와 구글 포토 버전, PC·폰의 완료 건수, 해당 화면의 상태 문구를 남긴다.

## 빌드

윈도우 실행 파일은 Go 1.24 이상에서 빌드한다.

```sh
desktop/build-windows.sh
(cd desktop && go test ./...)
```

APK는 JDK 또는 Eclipse Java Compiler, Android API 29의 android.jar, Android Build-Tools와 테스트 키 저장소를 사용한다.

```sh
ANDROID_JAR=/path/to/android-29/android.jar \
ANDROID_BUILD_TOOLS=/path/to/build-tools/34.0.0 \
PAB_SIGNING_KEY=/outside/repo/pab-test.jks android/build.sh
```

같은 APK를 업데이트하려면 같은 키로 서명해야 한다. Google API 키와 OAuth 클라이언트는 필요 없다.
